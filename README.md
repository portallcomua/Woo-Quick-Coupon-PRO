# Woo-Quick-Coupon-PRO
WooQuick Coupon 1.0 Це легкий утилітний плагін для WooCommerce, створений для максимально швидкої генерації купонів прямо з мобільного телефону або планшета
# 🎫 WooQuick Coupon Pro

**Швидке створення купонів для WooCommerce з режимом тестування (Quiz) та автоматичною перевіркою відповідей.**

## 📌 Основні можливості

| Функція | Опис |
|---------|------|
| ⚡ **Швидке створення** | Звичайний купон за 3 секунди |
| ❓ **Купон-квіз** | Користувач отримує знижку лише після правильної відповіді |
| 🔑 **Ліцензування** | 5 купонів безкоштовно, потім - вічна ліцензія |
| 🛠️ **Режим розробника** | На локальному сервері обмежень немає |
| 📱 **Адаптивний дизайн** | Працює на будь-яких пристроях |

## 🚀 Встановлення

1. Завантажте ZIP-архів плагіна
2. В адмінці WordPress: **Плагіни → Додати новий → Завантажити плагін**
3. Виберіть файл та натисніть **Активувати**

## 📖 Використання

### 1️⃣ Створення звичайного купона

| Поле | Приклад |
|------|---------|
| Код купона | `SALE2026` |
| Сума знижки | `15` |
| Тип | `Відсоток (%)` або `Фіксована сума (грн)` |

### 2️⃣ Створення купона-квіза (з питанням)

| Поле | Приклад |
|------|---------|
| Код купона | `UKRAINE10` |
| Питання | `Крим це` |
| Правильна відповідь | `Україна` |
| Сума знижки | `10` |
| Тип | `Відсоток (%)` |

### 3️⃣ Як це бачить клієнт

1. Клієнт вводить код купона `UKRAINE10` в кошику
2. З'являється модальне вікно з питанням: **"Крим це"**
3. Вводить відповідь: **"Україна"**
4. Купон активується, знижка застосовується

## 💰 Ліцензування

| Версія | Обмеження | Ціна |
|--------|-----------|------|
| **Безкоштовна** | До 5 купонів | 0 грн |
| **PRO** | Необмежено | 299 грн / $15 USD |

### Як активувати PRO-ліцензію

1. Після ліміту (5 купонів) з'явиться повідомлення
2. Перейдіть в розділ **Швидкий Купон Pro → 🔑 Ліцензія**
3. Натисніть **"Запит на оплату"** (прийде інструкція на email)
4. Після оплати отримаєте ліцензійний ключ
5. Введіть ключ → обмеження знімуться

### 🛠️ Режим розробника

Якщо сайт працює на локальному сервері (`localhost`, `127.0.0.1`, `.test`, `.dev`), **обмеження автоматично знімаються** для зручності розробки.

## ❓ Часті питання

**▶ Чи можна використовувати купони-квізи з іншими плагінами?**  
Так, це стандартні купони WooCommerce, вони сумісні з будь-якими плагінами.

**▶ Де зберігаються питання та відповіді?**  
В мета-полях купона (`_wq_quiz_question` та `_wq_quiz_answer`).

**▶ Що робити, якщо клієнт неправильно відповів?**  
Він може спробувати знову, поки не введе правильну відповідь.

**▶ Чи можна змінити питання після створення купона?**  
Так, через редагування купона в WooCommerce.
